## 🆕 CraftEase Projekt — Pregled

**Format:** 3 Sprinta × 1 dan &nbsp;|&nbsp; **Timovi:** Business (3) + Design (5) &nbsp;|&nbsp; **Alat:** Jira (Scrum)

**Ritam svakog sprint dana:**
```
9:00– 9:15   Sprint Planning u Jiri
9:15–10:00   Rad na deliverablima
10:00–10:15  ☕ Pauza
10:15–11:00  Rad na deliverablima
11:00–11:15  ☕ Pauza
11:15–12:00  Rad na deliverablima
12:00–12:30  Sprint Review + Retrospektiva u Jiri
```

| Sprint | Datum | Business Team | Design Team |
|--------|-------|---------------|-------------|
| **Sprint 1** | 23.04 | Problem statement, User Stories (draft) | Benchmark (3 konkurenta), Persona |
| **Sprint 2** | 05.05 | User Stories (finalno), IA input dokument | User Journey Map, Sitemap, User Flow, Lo-fi (3–4 screena) |
| **Sprint 3** | 07.05 | Wireframe review + pisani feedback | Hi-fi (DaisyUI, 3 screena) + klikabilni Figma prototip + Pitch |

**Finalni deliverable:** Tim prezentira produkt zajedno. Svaka studentica individualno prikazuje svoju Jira aktivnost i screene u Figmi.

Detaljan Jira backlog: [craft-ease-jira.md](./1-agile/extra/craft-ease-jira.md)

## 🎯 Pedagoške metode

- **Project Based Learning** — CraftEase projekt kroz cijeli UX modul
- **Scrum Simulacija** — Jira, sprintovi, daily standups, retrospektive
- **Hands-on Workshops** — Figma vježbe u svakoj UX sesiji
- **Peer Feedback** — Strukturirane kolaborativne sesije
- **Design Thinking** — Empathy → Ideate → Prototype → Test
- **Case Studies** — Analiza stvarnih IT projekata

## 📝 Napomene za facilitatora

- Svi materijali **na hrvatskom jeziku**
- **PM je primarni cilj** programa — UX/UI sadržaj prilagođen PM perspektivi
- **Jira/Scrum simulacija** = 60% fokus projekt dana; Figma dizajn = 40%
- **Sprint 1 (23.04)**: Počni s 10-min uvodom u Lean Startup/MVP koncepte (iz preskočenog Dana 9) — direktno se uklapa u problem statement vježbu
- **Dan 10 (28.04)**: Već ima ugrađen 10-min recap Empathize+Define faze — nije potrebna priprema za preskočeni Dan 9
- **Komprimirani dani** (30.04 i 24.04): fokus na PM-relevantne koncepte, preskočiti tehničke detalje
- Dan 30.04 — **double-header**: Accessibility 9:00–10:30 + Metrics 10:45–12:15 (s pauzom u sredini)
- **Sprint 3 (07.05)** je zadnji UX/UI dan — usability test koji studentice provode **direktno koristi protokol iz Dana 8**
- **PM = 8 dana**: preskočen samo M4 Dan 2 (Quality/Change/Risk)
